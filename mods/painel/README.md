
## Instalação

No prompt de uma sessão do Claude Code no terminal:

```
/plugin install painel --marketplace benlechuga/-lighthouse-imports
```

Pelo shell:

```
claude plugin install painel --marketplace benlechuga/-lighthouse-imports
```

No app desktop, onde `/plugin` não roda: clique em + ao lado da caixa do prompt, depois Plugins, Add marketplace com `benlechuga/-lighthouse-imports`, e então Add plugin.

## Desenvolvimento

claude plugin validate mods/painel
